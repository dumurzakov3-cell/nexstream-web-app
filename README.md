# NexStream — Modern Video Streaming & Shorts Web Platform ⚡

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/new)

**NexStream** — zamonaviy Dark Mode dizayniga ega, video kontent va vertikal Shorts formatini birlashtirgan interaktiv Web ilova.
Loyiha **Google Stitch** (AI Vibe Coding) orqali dizayn qilinib, **Antigravity** agenti yordamida to'liq ishlaydigan Web Single Page Application (SPA) darajasiga yetkazilgan.

---

## 🚀 Asosiy Imkoniyatlar
- 🎬 **Shorts Cinema Player:** 9:16 vertikal format, ambient neon orqa fon, dinamik layk/dislayk, interaktiv izohlar paneli (360px), klaviatura navigatsiyasi (`↑` / `↓` / `Space`).
- 📺 **Asosiy Sahifa (Home Feed):** 9 ta mavzu filtri, 4 ustunli video panjarasi, tezkor qidiruv tizimi, 16:9 modal pleyer.
- 🔔 **Obunalar (Subscriptions):** Obuna bo'lingan kanallar storis-karuseli va yangi yuklangan videolar lentasi.
- 🔍 **Kashfiyot (Explore):** Trenddagi toifalar va mashhur videolar reytingi (#1, #2, #3...).
- 📚 **Kutubxona (Library):** Ko'rishlar tarixi (progress bar bilan) va shaxsiy pleylistlar to'plami.
- 👤 **Profil & Sozlamalar:** Foydalanuvchi ma'lumotlari, statistika va dark mode sozlamalari.
- ➕ **Yuklash:** Yangi Video yoki Short qo'shish imkoniyati.

---

## 🛠 Texnologiyalar
- **Frontend:** HTML5, Tailwind CSS, JavaScript (ES6+), Material Symbols, Google Fonts (`Outfit`, `Manrope`).
- **Backend / Server:** Node.js HTTP Server (`server.js` — zero dependency).
- **Dizayn & Arxitektura:** Google Stitch AI Design System + Antigravity.
- **Joylashtirish (Deployment):** GitHub & Railway.

---

## 💻 Mahalliy Ishga Tushirish (Local Run)
1. Omborni klonlash:
   ```bash
   git clone https://github.com/USERNAME/nexstream-web-app.git
   cd nexstream-web-app
   ```
2. Serverni yoqish:
   ```bash
   npm start
   ```
3. Brauzerda ochish:
   ```
   http://localhost:3000
   ```

---

## 🚂 Railway'ga Joylashtirish (Deployment Guide)
1. Ushbu loyihani GitHub hisobingizga yuklang (`git push`).
2. [Railway.app](https://railway.app) ga kiring va **"New Project"** tugmasini bosing.
3. **"Deploy from GitHub repo"** ni tanlang va `nexstream-web-app` omborini tanlang.
4. Railway avtomatik ravishda `server.js` va `PORT` ni aniqlab, 1 daqiqada jonli efirga (Production URL) chiqaradi!
